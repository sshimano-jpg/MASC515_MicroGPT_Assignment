# MASC515 MicroGPT Assignment

This repository contains my working copy of Andrej Karpathy's `microgpt.py` implementation for the MASC515 MicroGPT assignment.

The purpose of this repository is to study a minimal GPT-style model and understand the main pieces of the architecture, including:

- token embeddings
- positional embeddings
- self-attention
- feedforward layers
- residual connections
- training loop
- text generation

## File

- `microgpt.py` — single-file MicroGPT implementation.

This project is being used for coursework in MASC515, Spring 2026.
