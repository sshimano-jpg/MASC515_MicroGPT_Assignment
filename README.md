# MASC515 MicroGPT Assignment

This repository contains my working copy of Andrej Karpathy's `microgpt.py` implementation for the MASC515 MicroGPT assignment. The updated implementation containing GELU, LoRA, RoPE, and Mixture of Experts is provided in `microgpt_updated.py`.

The purpose of this repository is to study a minimal GPT-style model and understand the main pieces of the architecture, including:

- token embeddings
- positional embeddings
- self-attention
- feedforward layers
- residual connections
- training loop
- text generation

## File

- `microgpt.py` — single-file MicroGPT implementation (raw code -- original).
- `microgpt_updated.py` — single-file MicroGPT implementation (updated code with GELU, LoRA, RoPE, and Mixture of Expert).
